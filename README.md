# Vinyl

A macOS app that draws a photorealistic spinning turntable as a live desktop layer — pinned above
your desktop picture, below your icons — with album art pulled live from Spotify or Apple Music.
Inspired by [vinylformac.com](https://vinylformac.com), written from scratch.

## Build

Requires full Xcode (not just the Command Line Tools) and [xcodegen](https://github.com/yonaskolb/XcodeGen):

```bash
brew install xcodegen
./scripts/build.sh
```

Installs to `/Applications/Vinyl.app`.
